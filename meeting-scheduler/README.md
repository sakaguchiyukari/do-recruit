# 会議日程調整ツール (Meeting Scheduler)

「調整さん」型の会議・打ち合わせ日程調整ツールのWordPressプラグインです。
30人以上の大人数でも、ログイン不要・オンラインで日程調整ができます。

## 特徴

- **誰でも使える** — ログイン・アカウント登録は一切不要。URLを開くだけ
- **何度でも使える** — 調整は何件でも作成可能。1回使い切りではなく、決定の取り消し・候補の追加もできる
- **調整同士が干渉しない** — 調整1件ごとに専用のランダムURL（24文字トークン）を発行。
  - 誰かが調整中でも、別の社員が新しい調整を同時に作成できる（お互いにブロックしない）
  - URLを知らない調整は一切見えない（公開の一覧ページは存在しない）
  - 幹事用URLと参加者用URLを分離。日程の決定・削除などの管理操作は幹事しかできない
- **同時回答に強い** — 回答は1人ごとに独立したレコードで保存されるため、複数人が同時に送信しても互いの回答を上書きしない
- **大人数対応** — 30人以上でも横スクロール＋固定列の集計表で見やすく表示。○△×の集計と「最も都合の良い候補」の自動ハイライト付き
- **スマホ対応** — レスポンシブデザイン。SWELLなど任意のテーマと併用可能

## インストール

1. `meeting-scheduler` フォルダごと `wp-content/plugins/` にアップロード
2. WordPress管理画面 →「プラグイン」→「会議日程調整ツール」を有効化
3. 完了。`https://あなたのサイト/?msched=new` が作成ページになります

社内ポータルなどの固定ページに入口を置く場合は、ショートコードを貼るだけです:

```
[meeting_scheduler]
```

## 使い方

### 幹事（調整を立ち上げる人）

1. 作成ページで会議名・候補日程（1行1候補）を入力して「作成」
2. 発行された2つのURLを控える
   - **参加者用URL** … メールやチャットで参加者全員に共有
   - **幹事用URL** … 自分だけが使う管理用URL（ブックマーク推奨。紛失すると幹事操作不可）
3. 回答が集まったら幹事用URLを開き、「この日程に決定する」で確定
   - 確定すると回答は締め切られ、全員のページに決定日程が表示されます

### 参加者

1. 共有されたURLを開く
2. 名前を入力し、各候補に ○ / △ / × を選んで送信
3. 予定が変わったら、集計表の自分の名前の下の「編集」から回答を修正

### 幹事ができるその他の操作（幹事用URLのみ）

- 決定の取り消し（再募集）
- 候補日程の追加（既存の回答はそのまま維持されます）
- メモ（会議室・ZoomのURL・議題など）の更新
- 特定の回答の削除
- 調整そのものの削除

## セキュリティと運用上の注意

- URLトークンを知っている人だけがアクセスできる「URLを知っている＝閲覧可」方式です。
  参加者用URLは社外の人に転送しないよう周知してください
- 幹事用URLは参加者に送らないでください（誤送信すると誰でも日程決定・削除ができてしまいます）
- 回答の「編集」は誰でも可能です（調整さんと同じ方式）。社内利用を想定した簡易運用です
- スパム対策としてハニーポット＋nonce検証、同一IPからの作成は1時間20件までの制限があります
- 検索エンジンには載りません（noindex, nofollow）
- 最終更新から **180日** を過ぎた調整は自動削除されます。日数を変えたい場合はテーマの
  `functions.php` に以下を追加してください（`0` で自動削除を無効化）:

```php
add_filter( 'msched_retention_days', function () { return 365; } );
```

## サイト管理者向け

WordPress管理画面の「日程調整」メニューから、全調整の一覧・回答数・URLの確認、
不要な調整の削除ができます（サイト管理者のみ）。
