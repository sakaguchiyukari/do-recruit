# AI Design Assistant

ヒアリング → デザイン提案 → ワイヤーフレーム生成、チラシ・バナー添削、レイヤー分解までを1画面で行う、デザイン事務所向けのAIアシスタントツールです。ビルド不要の静的HTML/CSS/JSのみで動作します。

## 機能

| タブ | 機能 |
|---|---|
| ① デザイン設計 | 業種・ターゲット・目的・サイズ・媒体をヒアリングし、レイアウト構成 / キャッチコピー(メイン5・サブ3・CTA3) / 配色パレット(hex付き) / フォント / 写真イメージ / デザインの理由を提案。レイアウトは**ワイヤーフレームSVG**としてプレビュー&ダウンロード可能 |
| ② デザイン添削 | チラシ・バナー画像(JPG/PNG/WebP)をアップロードすると、余白・視線誘導・文字量・配色・コントラスト・QRコード・CTAの7項目+総合を**100点満点で採点**し、「タイトルを20px大きく」のような具体的な改善案を優先度付きで提示 |
| ③ レイヤー分解 | 画像の構成要素(背景・写真・テキスト・ロゴ・CTA・QRなど)をAIが検出し、**レイヤー構造を持つSVG**として書き出し。Illustrator / Figma / Inkscape でグループ=レイヤーとして編集可能 |

SVG出力:ワイヤーフレーム / 配色パレット / レイヤー分解結果の3種類をダウンロードできます。

## 使い方

1. `index.html` をブラウザで開く(ローカルファイルのままでも、社内サーバーに置いてもOK)
2. 右上の「APIキー設定」から [Anthropic Console](https://console.anthropic.com/) で発行したAPIキーを登録
3. 各タブで入力・アップロードして実行

## 技術メモ

- モデル: `claude-opus-4-8`(adaptive thinking + structured outputs で常に整形済みJSONを取得)
- Anthropic Messages API をブラウザから直接呼び出し(`anthropic-dangerous-direct-browser-access` ヘッダー使用)
- 画像はAPI送信前に長辺2000pxへ自動縮小(トークン節約)。レイヤー切り抜きは元解像度で実行
- 依存ライブラリなし・ビルド不要

## セキュリティ上の注意

- APIキーは**このブラウザの localStorage にのみ**保存されます。サーバーには送信されません
- ただしキーを入れたブラウザを共有PCで使う場合は、利用後に「APIキー設定 → 削除」を推奨します
- このツールを**インターネット上に公開する場合は、APIキーを各利用者が自分で入力する運用**にしてください(HTMLにキーを埋め込まないこと)
