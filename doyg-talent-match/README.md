# DO MATCH — 副業・リファラル採用マッチング（社内コミュニティ）

ドゥ.ヨネザワ企業グループの社内向けページ。グループ内の **副業案件** と **リファラル採用の求人** を、
案件タイプに合わせた条件で検索し、入力条件との一致度（マッチ度）を表示する。

## ファイル構成

```
doyg-talent-match/
├─ index.html                        … ページ本体（カードは <template> を JS で複製して描画）
├─ assets/
│   ├─ css/style.css                 … CSS 1ファイル（FLOCSS 順 + BEM）
│   ├─ js/main.js                    … JS 1ファイル（defer）。案件データもここ
│   ├─ img/hero/hero-community.svg   … 仮画像（写真に差し替え）
│   ├─ img/ogp/ogp-talent-match.png  … 未作成（1200×630 PNG を用意）
│   └─ icon/favicon.svg / apple-touch-icon.png（PNG は未作成）
└─ README.md
```

`type="module"` を使わず `defer` の単一ファイルにしているため、HTML をブラウザで直接開いても動作する。
パスは相対パス（リポジトリ内のサブディレクトリに置いているため）。

## 検索・マッチングの仕様

| 区分 | 条件 | 挙動 |
|---|---|---|
| 絞り込み（共通） | 案件タイプ / キーワード / 事業領域 | 一致しない案件は表示しない |
| マッチング（副業） | スキル 50点 / 稼働時間 25点 / 働き方 25点 | 点数化して 0〜100% で表示 |
| マッチング（リファラル） | 知人の経験職種 50点 / 雇用形態 25点 / 勤務エリア 25点 | 同上 |

- 未入力の条件は分母から除外する（例：スキルのみ入力ならスキルだけで100%換算）
- マッチング条件が未入力の案件はマッチ度を表示しない
- 案件タイプを「副業」にするとリファラル条件は非表示・無効化される（逆も同様）
- 締切日を過ぎた案件は自動で非表示。締切7日以内は「締切まであと○日」を強調
- 配点は `main.js` の `WEIGHT`、しきい値は `MATCH_THRESHOLD` で変更できる

## 案件データの差し替え

`assets/js/main.js` の `JOBS` 配列が案件データ。**現在の内容はすべて画面確認用のサンプル**。
本番では API / スプレッドシート等から同じ形のデータを取得して `JOBS` を置き換える。
