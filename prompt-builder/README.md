# 画像プロンプトビルダー（Image Prompt Builder）

「こういう画像が欲しいけど、うまく言葉にできない」を解決する単体HTMLツール。
近い**型（テンプレート）**を選び、キーワードのチップを**クリックで足していく**だけで、
そのまま貼れる英語／日本語のプロンプトが組み上がります。

## 使い方

`index.html` を**ブラウザで開くだけ**。インストール・ネット接続・アカウント登録すべて不要。
ライブラリ外部依存なし、1ファイルで完結し、入力内容はどこにも保存・送信されません。

1. **STEP 1** — 近い「型」を1つ選ぶ（採用ビジュアル／人物／商品／料理／風景／イラスト／ロゴ／SNSバナー／建築・内装／フリー）
   - 型を選ぶと、その用途でよく使う要素とおすすめの縦横比が自動でセットされます。
2. **STEP 2** — 何を描くか（主題）を日本語で入力。型ごとの例文をクリックしても入ります。
3. **STEP 3** — 画風・構図・ライティング・色・雰囲気・背景・品質・縦横比をチップで選ぶ（クリックで選択／解除）。
4. **RESULT** — 右パネルに英語（推奨）と日本語（確認用）のプロンプトが即時生成。ボタンでコピー。

## 特徴

- **クリックで組み立て** — ゼロから文章を書かず、キーワードを選ぶだけ。各チップは日本語ラベルと英語表現の対訳付き。
- **モデル別に自動整形** — 汎用/DALL·E/nano banana（自然文）、Midjourney（`--ar` 付き）、Stable Diffusion（キーワード＋ネガティブ別欄）を切り替え可能。
- **日本語プロンプトも同時生成** — 何を指定しているか日本語で確認しながら使える。
- **ネガティブプロンプト** — チェック1つで低品質・崩れ防止のネガティブを付与。

## カスタマイズ

型やチップは `index.html` 内の `TEMPLATES` / `GROUPS` 配列を編集するだけで増減できます。
各項目は `{ja:"日本語ラベル", en:"english term"}` の形式です。
