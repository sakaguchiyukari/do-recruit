Image Prompt Builder

型を選んで、画像プロンプトを組み立てる

「こういう画像が欲しいけど、うまく言葉にできない」を解決するツール。近い型（テンプレート）を選び、キーワードをクリックで足していくだけで、そのまま貼れる英語／日本語のプロンプトが完成します。

STEP 1 型（テンプレート）を選ぶ 近いものを1つ
STEP 2 何を描く？（主題） 日本語でOK
STEP 3 雰囲気の要素を足す クリックで選択・解除
RESULT 完成プロンプト
英語プロンプト推奨
左で型と要素を選ぶと、ここにプロンプトが組み上がります。

英語プロンプトはほとんどの画像生成AI（DALL·E / nano banana / Midjourney / Stable Diffusion 等）で精度が高く出やすいため推奨。
モデルを切り替えると、そのAI向けの書き方（Midjourneyの --ar など）に自動整形されます。すべてこの1ファイルで完結・保存されません。
