# Do.Link 運用ログ（PHP版）

Claude のアーティファクトで作った「Do.Link 運用ログ」を、**Claude に登録していない人でも見られる**Webサイトにしたものです。
PHP が動くサーバーにフォルダごとアップロードするだけで使えます（データベースの準備は不要）。

- 閲覧：URLを開くだけ（ログイン不要）
- 記録：ページ下部の「管理者ログイン」からパスワードを入れた人だけが追加・編集・削除できます
- 自動同期：開いている全員の画面に、60秒ごと（＋タブに戻ったとき）最新の記録が反映されます
- 書き出し：誰でも Excel / CSV でダウンロードできます
- GA4：管理者がGA4のCSVを取り込むと、アクセス推移と作業日を重ねて表示します

## 動作環境

- PHP 8.0 以上（拡張機能 `pdo_sqlite` と `mbstring` が有効なもの）
  - エックスサーバー・さくらのレンタルサーバ・ConoHa WING など、WordPress が動く一般的なレンタルサーバーなら通常は満たしています
- Apache（`.htaccess` が使えるサーバー）を推奨。Nginx の場合は「注意事項」を参照

## フォルダ構成

```
dolink-log/
├── index.php              … ページ本体
├── api.php                … データの読み書き（画面から自動で呼ばれる）
├── config.php             … ★設定（管理者パスワード）
├── .htaccess              … config.php を外から見えなくする
├── inc/bootstrap.php      … 共通処理（データベース・ログインなど）
├── data/                  … データの保存場所（初回アクセス時に自動作成）
├── migration/             … Claude版のデータ（初回アクセス時に自動で取り込み）
│   ├── logs.csv
│   └── ga4.csv
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── img/logo-dolink.png
```

## 設置手順（3ステップ）

### 1. 管理者パスワードを決める

`config.php` を開き、次の行を書き換えて保存します。

```php
'admin_password' => 'change-me-please',
```

→ 12文字以上の英数字を推奨（例：`DoLink-2026-xxxx`）。初期値のままではログインできません。

### 2. サーバーにアップロードする

`dolink-log` フォルダを丸ごと、FTP やサーバーのファイルマネージャーでアップロードします。

例：`public_html/dolink-log/` に置くと `https://（ドメイン）/dolink-log/` で開けます。

### 3. ブラウザで開く

URLを開くと、自動で次の処理が行われます。

- `data/` フォルダにデータベースファイルが作られる
- `migration/` の Claude 版データ（作業ログ・GA4の9月〜10/6分）が取り込まれる

画面が表示されれば完了です。URL を社内に共有してください。

## うまく表示されないとき

| 症状 | 確認すること |
| --- | --- |
| 「データを読み込めませんでした」と出る | `data` フォルダの書き込み権限（パーミッション 755 か 775）／PHP のバージョン（8.0以上） |
| 真っ白な画面・500エラー | サーバー管理画面の「PHPバージョン設定」で 8.0 以上を選ぶ |
| ログインできない | `config.php` のパスワードを初期値から変更したか／入力ミスがないか |
| 「ページの有効期限が切れました」 | ページを再読み込みしてから操作する |

## 使い方

- **閲覧する人**：URLを開くだけ。月送り・カテゴリ絞り込み・キーワード検索・Excel/CSV書き出しが使えます
- **管理者**：ページ最下部の「管理者ログイン」→ パスワードを入力。ログイン状態はそのブラウザで30日間続きます
- **GA4**：管理者ログイン後、グラフ下の「GA4のCSVを取り込む」から、GA4（または管理会社）から受け取ったCSVを読み込みます。同じ日付は上書きされます

## 注意事項

- **公開範囲**：URLを知っている人は、ログインなしで全記録を閲覧できます。社外秘の内容は記録しないでください。検索エンジンには載らない設定（`noindex`）にしています
- **バックアップ**：記録はすべて `data/dolink-log.sqlite` の1ファイルに入っています。定期的にダウンロードして保管するか、画面の「全期間」→「Excelで書き出す」で控えを取ってください
- **Nginx のサーバー**：`.htaccess` が効かないため、`config.php` の `db_path` を Web 公開領域の外（例：`/home/ユーザー名/dolink-log-data/dolink-log.sqlite`）に変更してください
- **再取り込みについて**：`migration/` のCSVは最初の1回だけ読み込まれます。2回目以降に置き換えても反映されません
