# Do.Link 運用ログ（静的サイト版）

Claude のアーティファクトで作った「Do.Link 運用ログ」を、**Claude に登録していない人でも見られる**普通のWebページに作り替えたものです。

- 閲覧：URLを開くだけ（ログイン不要）
- 記録：管理者キーでログインした人だけが、画面のフォームから追加・編集・削除できます
- 保存先：Google スプレッドシート（シートを直接編集してもOK）
- 自動同期：ページは5分ごと＋タブに戻ったときに最新内容を読み込み直します
- GA4：閲覧権限をもらえれば毎朝自動で取り込み／もらえなければ従来どおりCSV取り込み

## フォルダ構成

```
dolink-log/
├── index.html               … ページ本体
├── assets/
│   ├── css/style.css        … スタイル（1ファイル・CSS変数でカラー管理）
│   ├── js/config.js         … ★設定（Apps Script のURLを書く）
│   ├── js/main.js           … 画面の動作
│   ├── img/logo-dolink.png  … ロゴ
│   └── data/demo.json       … URL未設定時のデモ表示用データ
├── gas/
│   ├── Code.gs              … スプレッドシート側のプログラム
│   └── appsscript.json      … Apps Script の設定
└── migration/
    ├── logs.csv             … Claude版から移行する作業ログ
    └── ga4.csv              … Claude版から移行するGA4日別データ
```

## 導入手順

### 1. スプレッドシートと Apps Script を用意する

1. Google ドライブで新しいスプレッドシートを作成（名前例：`Do.Link 運用ログ`）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消し、`gas/Code.gs` の内容を貼り付けて保存
4. 左メニュー「プロジェクトの設定」（歯車）→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
5. エディタに出てきた `appsscript.json` を `gas/appsscript.json` の内容に置き換えて保存

### 2. 管理者キーを設定する

「プロジェクトの設定」→「スクリプト プロパティ」→「スクリプト プロパティを追加」

| プロパティ | 値 |
| --- | --- |
| `ADMIN_KEY` | 管理者だけが知る合言葉（**16文字以上のランダムな英数字を推奨**） |

### 3. 初期設定を実行する

エディタ上部の関数選択で `setup` を選び「実行」を押します。初回は Google の承認画面が出るので許可してください。
「作業ログ」「GA4」の2シートが作られ、見出しの色・列幅・カテゴリのプルダウンが設定されます。

### 4. Claude版のデータを移す

1. 「作業ログ」シートを開き、セル **A1** を選んで「ファイル」→「インポート」→ `migration/logs.csv` をアップロード
   →「インポート場所：選択したセルを起点にデータを置換」
2. 「GA4」シートでも同じように `migration/ga4.csv` をインポート
3. もう一度 `setup` を実行して見た目を整える

### 5. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 「次のユーザーとして実行」：**自分**／「アクセスできるユーザー」：**全員**
3. 表示された URL（末尾が `/exec`）をコピー
4. `assets/js/config.js` の `apiUrl: ''` に貼り付けて保存

> `Code.gs` を後から修正したときは「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」で更新します（URLは変わりません）。

### 6. ページを公開する

`dolink-log` フォルダを丸ごと、任意のWebサーバーに置きます。

- **自社サーバー／レンタルサーバー**：FTP 等でアップロード（例：`https://example.com/dolink-log/`）
- **GitHub Pages**：リポジトリの Settings → Pages で公開ブランチ・フォルダを指定

※ `index.html` をダブルクリックで直接開くと、ブラウザの制限でデータを読み込めない場合があります。必ずWebサーバー経由で開いてください。

## 使い方

- **閲覧する人**：URLを開くだけ。月送り・カテゴリ絞り込み・キーワード検索・Excel/CSV書き出しが使えます
- **管理者**：ページ最下部の「管理者ログイン」→ 管理者キーを入力。以降その端末ではログイン状態が続きます
- **スプレッドシートで直接記録してもOK**：「作業ログ」シートに日付・事業名・カテゴリ・作業内容を入力すれば、IDは自動で振られます（ID列は非表示にしてあります。削除しないでください）

## GA4 の自動同期（任意）

GA4 のメイン管理者が他社の場合、**次のどちらか**で運用します。

### A. 自動同期（おすすめ）

1. 他社の管理者に依頼し、Apps Script を作った Google アカウントに GA4 プロパティの **「閲覧者」権限**を付けてもらう
2. GA4 の「管理」→「プロパティの詳細」で **プロパティID（数字）** を確認
3. スクリプト プロパティに `GA4_PROPERTY_ID` を追加して数字を入力
4. 関数 `syncGa4Full` を1回実行（過去400日分を取り込み。初回は追加の承認が出ます）
5. 関数 `createDailyTrigger` を1回実行（以後、毎朝6時台に直近35日分を自動更新）

取り込む指標は「表示回数」「アクティブ ユーザー」「イベント数」です。変える場合は `Code.gs` の `GA4_METRICS` を編集します。

### B. 権限がもらえない場合

管理者ログイン後、グラフ下の「GA4のCSVを取り込む」から、他社から受け取った（または探索レポートで書き出した）CSV を取り込みます。

## 注意事項

- **公開範囲**：ページURLと Apps Script のURLを知っている人は、ログインなしで**全記録を閲覧できます**。社外秘の内容は記録しないでください。検索エンジンには載らない設定（`noindex`）にしています
- **管理者キー**：ブラウザ（localStorage）に保存されます。共用PCでは使用後に「ログアウト」してください。キーを変えたいときはスクリプト プロパティの `ADMIN_KEY` を変更します
- **反映のタイミング**：負荷軽減のため、読み込み結果を最大30秒キャッシュしています。画面からの記録は即時、シートの直接編集は最大で「30秒＋自動同期の間隔（5分）」で反映されます
