# Do.Link — リファラル採用ページ（下層ページ）

ドゥ.ヨネザワ企業グループの社員限定コミュニティサイト「Do.Link」の下層ページ。
グループで募集中の求人を、紹介したい知人の経験・希望の働き方からさがし、そのまま紹介フォームを送れる。
デザインは Do.Link TOP（空色のヒーロー / 白い角丸カード / 黄色のCTA / 英字見出し）に合わせている。

**このファイルはページの「中身」だけ。** ヘッダー・フッター・パンくずは Do.Link 側の共通テンプレートで
表示する前提のため含めていない（`<main>` の中身と、SP固定CTA・紹介モーダルが組み込み対象）。

※ 副業マッチングは今回の範囲外のため削除した（以前の版は git 履歴に残っている）。

## ファイル構成

```
do-link/
├─ referral/
│   └─ index.html                         … リファラル採用ページ（カードは <template> を JS で複製して描画）
├─ assets/
│   ├─ css/style.css                      … CSS 1ファイル（FLOCSS 順 + BEM）
│   ├─ js/main.js                         … JS 1ファイル（defer）。求人データもここ
│   ├─ img/ogp/ogp-referral.png           … 未作成（1200×630 PNG を用意）
│   └─ icon/favicon.svg / apple-touch-icon.png（PNG は未作成）
└─ README.md
```

- `type="module"` を使わず `defer` の単一ファイルにしているため、HTML をブラウザで直接開いても動作する

## 検索・マッチングの仕様

| 区分 | 条件 | 挙動 |
|---|---|---|
| 絞り込み | キーワード / 事業領域 | 一致しない求人は表示しない |
| マッチング | 知人の経験職種 50点 / 雇用形態 25点 / 勤務エリア 25点 | 点数化して 0〜100% で表示 |

- 未入力の条件は分母から除外する（例：職種のみ選択なら職種だけで100%換算）
- 条件が未入力のときはマッチ度を表示しない
- 締切日を過ぎた求人は自動で非表示。締切7日以内は「締切まであと○日」を強調
- 配点は `main.js` の `WEIGHT`、しきい値は `MATCH_THRESHOLD` で変更できる

## パスワード画面

- **初期パスワード：`dolink2026`**（仮。運用前に必ず変更する）
- 一度入力すると、そのタブを閉じるまで再入力は不要（sessionStorage）
- パスワードはソースに直接書かず、SHA-256 のハッシュ値（`main.js` の `PASSWORD_HASH`）で照合する
- 変更方法は `main.js` の「11. パスワードゲート」のコメントを参照

> ⚠️ **これは簡易ロックであり、セキュリティ対策ではない。**
> ブラウザ内だけで判定しているため、ファイルを直接読めば中身は見られる。
> Do.Link 本体にログイン機能がある場合は、このパスワード画面は不要（削除してよい）。
