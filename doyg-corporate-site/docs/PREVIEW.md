# 表示の確認方法

制作中のサイトを実際にブラウザで見るための手順です。目的に応じて3つあります。

---

## 方法1：GitHub Pages で見る（おすすめ・スマホでも確認できる）

URLが発行されるので、**PCでもスマホでも、関係者に共有しても**確認できます。

### 手順

1. GitHubのリポジトリで **Settings**（設定）タブを開く
2. 左メニューの **Pages** をクリック
3. **Build and deployment** の **Source** を **「GitHub Actions」** に変更
4. **Actions** タブを開き、`Deploy preview to GitHub Pages` が緑のチェックになるのを待つ（1〜2分）
5. 表示されたURLを開く

```
https://sakaguchiyukari.github.io/do-recruit/
```

### 更新のタイミング

`claude/do-yonezawa-corporate-site-otpvdz` ブランチに変更が入るたび、**自動で公開が更新されます**。
手動で実行したい場合は Actions タブ →「Deploy preview to GitHub Pages」→「Run workflow」。

### 注意

- このURLは**公開**されます（リポジトリがPublicのため、URLを知っていれば誰でも見られます）。
  社外に出したくない段階では、方法2のローカル確認をお使いください。
- 検索エンジンに載せたくない場合は、公開前に `robots.txt` で除外します（Phase4で対応）。

---

## 方法2：自分のPCで見る（社外に出さずに確認したい場合）

### 手順

1. GitHubの緑の **Code** ボタン →「Download ZIP」でダウンロードし、展開する
2. `doyg-corporate-site` フォルダの場所で、ターミナル（Macは「ターミナル」、Windowsは「PowerShell」）を開く
3. 次のどちらかを実行する

```bash
# Python が入っている場合（Macは標準で入っています）
python3 -m http.server 8000

# Node.js が入っている場合
npx serve .
```

4. ブラウザで `http://localhost:8000/` を開く

終了するときはターミナルで `Ctrl + C`。

---

## 方法3：index.html をダブルクリックする（簡易確認）

すぐ見られますが、**制限があります**。

| 項目 | 状態 |
|---|---|
| レイアウト・文字・色・余白 | ✅ 確認できる |
| 写真 | ✅ 確認できる |
| アイコン（矢印など） | ❌ 表示されない |
| スクロール時のフェード演出 | ❌ 動かない（内容は表示されます） |
| メニューの開閉 | ❌ 動かない |

ブラウザのセキュリティ制限（`file://` で開くと外部ファイルの読み込みが制限される）によるものです。
**サイトの不具合ではありません。** 正しく確認するには方法1か方法2をお使いください。

なお、この状態でも**文章が消えることはありません**。JavaScriptが動かない環境では、
スクロール演出用の初期状態（非表示）を自動的に解除する仕組みを入れてあります。

## 確認するときの見どころ（Phase1）

| セクション | 確認ポイント |
|---|---|
| Hero | キャッチコピーの見え方、余白の量 |
| About | 写真とテキストのバランス |
| Mission | ネイビー全面の印象、MVVの読みやすさ |
| Business | 4事業が「カードでない」見せ方になっているか |
| Group | 数字の大きさ、企業規模が伝わるか |
| Sustainability | 取り組みの伝わり方 |
| News | 一覧の読みやすさ（日付の桁揃え） |
| Recruit | 採用CTAの強さ |

**ブラウザの幅を変えてみてください。** PC→タブレット→スマホと自動で組み替わります。
スマホ幅では画面下に「採用情報を見る」の固定ボタンが出ます。
