# 採用日程管理アプリ

担当者ごとにアカウント(名前+自分で設定するパスワード)を作成して使える、採用日程の管理アプリです。

## 機能

- **誰でも使える**: 初回に「新規登録」から担当者名とパスワードを登録すればすぐ利用開始
- **パスワードは各自で設定**: 管理者による配布は不要。ログイン後に自分で変更も可能
- **日程のタイトルを自由に作成**: 「一次面接(山田さん)」「会社説明会」など内容がわかるタイトルを付けて日程を登録
- 日付・時刻・場所・メモ・ステータス(予定/完了/キャンセル)の管理
- 「今後の予定」「自分の担当」「すべて」の絞り込み表示
- 各日程に作成した担当者名を表示

## Netlifyへのデプロイ方法

### 方法1: ドラッグ&ドロップ(かんたん)

1. [Netlify](https://app.netlify.com/) にログイン
2. 対象サイト(lambent-bubblegum-4ccdcb)の **Deploys** タブを開く
3. この `schedule-app` フォルダをそのままドラッグ&ドロップ

### 方法2: GitHub連携

1. Netlifyのサイト設定で **Build & deploy → Link repository** からこのリポジトリを選択
2. **Publish directory** に `schedule-app` を指定

## 注意事項

- データ(アカウント・日程)はブラウザの `localStorage` に保存されます。**同じ端末・同じブラウザ内でのみ共有**され、別の端末とは自動同期されません
- パスワードはSHA-256でハッシュ化して保存しています(平文では保存されません)
- 端末をまたいでデータを共有したい場合は、Firebase/Supabaseなどのバックエンド追加が必要です
