    全7カテゴリ・29項目

    01

    サイト本体・CMS

    0 / 8

    • WordPress本体の更新

      「ダッシュボード > 更新」で最新版になっているか。セキュリティ修正を含むマイナーリリースは、標準で自動更新される設定になっている。

      「WordPress本体の更新」の確認状況

    • テーマの更新

      使用中のテーマ（子テーマを使っている場合は親テーマ）が最新か。親テーマを直接編集していると、更新で変更が消えるため注意する。

      「テーマの更新」の確認状況

    • プラグインの更新

      「プラグイン」画面に更新の通知がないか。更新前にバックアップを取り、更新後に表示とフォームを確認する。

      「プラグインの更新」の確認状況

    • 不要なプラグイン・テーマの削除

      停止しているだけのプラグイン・テーマもサーバー上にファイルが残り、攻撃の対象になり得る。使わないものは削除する。

      「不要なプラグイン・テーマの削除」の確認状況

    • 更新が止まったプラグインの有無

      WordPress.org の配布ページで最終更新日を確認する。長期間更新がない、または配布停止のものは代わりを検討する。

      「更新が止まったプラグインの有無」の確認状況

    • PHPバージョン

      「ツール > サイトヘルス」またはサーバー管理画面で確認する。php.net でサポート期間内のバージョンか（PHP 8.2 のサポートは2026年12月末に終了予定）。

      「PHPバージョン」の確認状況

    • セキュリティ対策プラグインの稼働

      プラグインが有効になっているか、通知メールが届いているか、スキャン結果に警告がないか、有料版の場合はライセンスの期限が切れていないか。

      「セキュリティ対策プラグインの稼働」の確認状況

    • コメント・投稿の不審な内容

      身に覚えのない投稿・固定ページ・リンクがないか。コメント機能を使っていない場合は「設定 > ディスカッション」で無効にする。

      「コメント・投稿の不審な内容」の確認状況
    02

    アカウント・ログイン

    0 / 4

    • 管理者アカウントの棚卸し

      「ユーザー」画面で権限「管理者」を絞り込み、不要なアカウントを削除する。見覚えのない管理者は不正侵入の兆候のため要注意。

      「管理者アカウントの棚卸し」の確認状況

    • 二段階認証の設定

      WordPress本体には二段階認証の機能がないため、プラグインで導入する。管理者権限を持つアカウントすべてに設定されているか。

      「二段階認証の設定」の確認状況

    • 不審なログイン履歴

      WordPress本体はログイン履歴を残さないため、セキュリティプラグインのログやサーバーのアクセスログで、見覚えのない日時・場所からのログインがないか確認する。

      「不審なログイン履歴」の確認状況

    • ログイン画面の保護

      ログイン試行回数の制限、IPアドレスでのアクセス制限、使っていない場合のXML-RPC無効化などが設定されているか。ユーザー名に「admin」を使っていないか。

      「ログイン画面の保護」の確認状況
    03

    サーバー

    0 / 6

    • サーバー管理画面の二段階認証

      レンタルサーバーの契約者ページ・コントロールパネルのログインに二段階認証が設定されているか。

      「サーバー管理画面の二段階認証」の確認状況

    • サーバー・FTPアカウントの棚卸し

      退職者や過去の制作会社に発行したFTP・SSH・データベースのアカウントが残っていないか。共有していたパスワードは変更する。

      「サーバー・FTPアカウントの棚卸し」の確認状況

    • ファイル転送の暗号化（SFTP / FTPS）

      通常のFTPはIDとパスワードが暗号化されずに送られる。FTPクライアントの接続設定がSFTPまたはFTPSになっているか。

      「ファイル転送の暗号化（SFTP / FTPS）」の確認状況

    • WAF（不正アクセス防止機能）の有効化

      サーバー管理画面でWAFが「有効」になっているか。有効化後は、誤検知でフォーム送信や管理画面の保存が止まっていないかも確認する。

      「WAF（不正アクセス防止機能）の有効化」の確認状況

    • アクセスログ・エラーログの確認

      wp-login.php・xmlrpc.php への短時間の大量アクセスや、.env などの存在しないファイルへのアクセスがないか。PHPエラーが急に増えていないか。

      「アクセスログ・エラーログの確認」の確認状況

    • 不審なファイルの有無

      置いた覚えのないPHPファイル、最近更新された見覚えのないファイルがないか。通常、wp-content/uploads 内にPHPファイルは置かれない。

      「不審なファイルの有無」の確認状況
    04

    ドメイン・DNS

    0 / 4

    • ドメインの有効期限

      有効期限・自動更新の設定、登録しているクレジットカードの期限、登録メールアドレスが受信できるかを確認する。失効すると第三者に取得される恐れがある。

      「ドメインの有効期限」の確認状況

    • ドメイン管理画面の二段階認証

      ドメインを登録している会社の管理画面のログインに二段階認証が設定されているか。

      「ドメイン管理画面の二段階認証」の確認状況

    • DNS設定に不審な変更がないか

      ネームサーバー、A・CNAME・MX・TXTレコードが意図どおりか。解約済みのサービスを指したままのサブドメインがないか。

      「DNS設定に不審な変更がないか」の確認状況

    • メールのなりすまし対策（SPF・DKIM・DMARC）

      SPF・DKIM・DMARCのレコードが設定されているか。メールを送らないドメインでも、SPF「v=spf1 -all」とDMARCで送信元の詐称を防げる。

      「メールのなりすまし対策（SPF・DKIM・DMARC）」の確認状況
    05

    SSL・通信

    0 / 2

    • SSL証明書の有効期限

      証明書の有効期限と自動更新が機能しているか。公開SSL証明書の最長有効期間は2026年3月から200日に短縮され、今後さらに短くなる予定のため、自動更新の確認が重要。

      「SSL証明書の有効期限」の確認状況

    • 常時SSL（httpからhttpsへの転送）

      http:// や www の有無を変えてアクセスし、https:// に転送されるか。「設定 > 一般」の2つのアドレスが https か。画像などが http で読み込まれていないか。

      「常時SSL（httpからhttpsへの転送）」の確認状況

    0 / 2

    • バックアップの取得状況

      ファイルとデータベースの両方が、自動で定期的に取得されているか。最終取得日時と保存世代数、保存先がサイトと同じサーバーだけになっていないか。

      「バックアップの取得状況」の確認状況

    • 復元手順の確認

      復元の手順書があり、担当者が決まっているか。実際に復元できるかを、テスト環境などで一度試しておく。

      「復元手順の確認」の確認状況

    0 / 3

    • セキュリティ診断レポートの確認

      無料の診断サービスやセキュリティプラグインの結果に警告がないか。前回指摘された項目が対応済みか。

      診断ツールと進め方を見る
      「セキュリティ診断レポートの確認」の確認状況

    • サイトの表示・改ざんの確認

      PCとスマートフォンで主要ページを確認する。検索結果やスマホからの訪問時だけ別サイトへ転送する手口もある。Google Search Console の「セキュリティの問題」も確認する。

      「サイトの表示・改ざんの確認」の確認状況

    • 問い合わせフォームの動作確認

      実際にテスト送信し、管理者通知と自動返信メールが届くか（迷惑メールフォルダも確認）。スパム対策（reCAPTCHA等）が動作しているか。

      「問い合わせフォームの動作確認」の確認状況

    サイト本体

    0 / 5

    • フォーム・プログラムの更新

      メールフォームなどのプログラムが配布元の最新版か、配布が終了していないか。サーバーのPHPバージョンがサポート期間内か。

      「フォーム・プログラムの更新」の確認状況

    • 不要ファイルが公開されていないか

      旧ページ・テストページ、.bak や .zip などのバックアップ、.git フォルダ、.env、phpinfo.php などが公開ディレクトリに残っていないか。

      「不要ファイルが公開されていないか」の確認状況

    • ファイル一覧が見えないか

      index.html を置いていないフォルダ（例：/images/）のURLを開き、ファイル一覧が表示されないか。Apacheでは .htaccess の「Options -Indexes」で止められる。

      「ファイル一覧が見えないか」の確認状況

    • リンク切れ・外部リンク先の確認

      リンク切れがないか。リンク先のドメインが失効して、第三者の別サイトになっていないか。

      「リンク切れ・外部リンク先の確認」の確認状況

    • 外部から読み込むスクリプトの確認

      解析タグ・広告タグ・CDN・外部ウィジェットの読み込み元が現存し、信頼できるか。使っていないタグは削除する。2024年には配信ドメインの所有者が変わり不正なコードが配信された例（polyfill.io）がある。

      「外部から読み込むスクリプトの確認」の確認状況

    How to check

    セキュリティ診断の進め方

    特別な契約がなくても、無料のサービスで外部から確認できます。URLを入力するだけのものが中心です。診断は、管理を任されているサイトに対してのみ行ってください。

    1. 毎月：危険サイト判定・改ざんの有無を見る

      Google Search Console の「セキュリティの問題」と、セーフブラウジングのサイトステータスで警告が出ていないかを確認します。あわせて Sucuri SiteCheck にURLを入れ、マルウェアやブラックリスト登録の警告がないかを見ます。

    2. 毎月（WordPress）：プラグインのスキャン結果を見る

      Wordfence などのセキュリティプラグインでスキャンを実行し、警告の内容を確認します。「ツール > サイトヘルス」の「おすすめの改善」も確認します。

    3. 四半期ごと：通信・メールの設定を診断する

      SSL Labs で証明書と暗号化の設定を、HTTP Observatory でセキュリティヘッダーを、MXToolbox で SPF・DMARC の設定を確認します。

    4. 結果を記録する

      問題がなければ「OK」、警告があれば「要検討」にして、ツール名と警告の内容をメモ欄に残します。評価（A〜Fなど）も書いておくと、次回と比べられます。

    全サイト共通（ブラウザだけで使える無料サービス）

    • 改ざん・危険判定

      Google Search Console

      「セキュリティと手動による対策 > セキュリティの問題」で、Googleが検出したハッキングやマルウェアを確認できる。事前にサイトの所有権の確認が必要。

      Search Console を開く

    • 改ざん・危険判定

      Google セーフブラウジング サイトステータス

      URLを入力すると、Googleが危険なサイトと判定していないかを確認できる。登録不要。

      サイトステータスを開く

    • マルウェア

      Sucuri SiteCheck

      URLを入力すると、外から見える範囲のマルウェア・不正なリダイレクト・ブラックリスト登録を調べる。サーバー内部のファイルまでは調べられない。

      SiteCheck を開く

    • SSL

      Qualys SSL Labs（SSL Server Test）

      証明書の有効期限と、暗号化の設定をA〜Fで評価する。結果が出るまで1〜2分かかる。

      SSL Server Test を開く

    • セキュリティヘッダー

      HTTP Observatory（Mozilla）

      HTTPS転送やセキュリティ関連のヘッダーの設定状況を採点する。改善点も一覧で表示される。

      HTTP Observatory を開く

    • メール

      MXToolbox

      ドメインを入力し、SPF・DMARC・DKIMのレコードの有無や誤りを確認できる。メールサーバーのブラックリスト登録も調べられる。

      MXToolbox を開く

    WordPressのみ（管理画面・プラグイン）

    • 標準機能

      サイトヘルス

      「ツール > サイトヘルス」で、PHPバージョン、停止中のプラグイン・テーマ、HTTPSの状態などの改善点を確認できる。

    • プラグイン

      Wordfence Security

      無料版で、マルウェア・改ざんファイルのスキャンや、脆弱性のあるプラグインの検出ができる。無料版は、新しい攻撃への対策ルールの反映が有料版より遅れる。

      配布ページを開く

    • プラグイン

      SiteGuard WP Plugin

      日本製のプラグイン。ログインページの変更・画像認証・ログイン履歴の記録などで、管理画面を守る。マルウェアのスキャン機能はない。

      配布ページを開く

    このほか、レンタルサーバーによってはウイルスチェックや改ざん検知の機能があります。サーバーの管理画面に診断結果のページがないかも確認してください。

    ご利用にあたって

    • 本チェックリストの内容は2026年11月時点の情報にもとづきます。PHPのサポート期間やSSL証明書の有効期間、各サービスの仕様は変わるため、公式情報で最新の状況を確認してください。
    • 進捗の「完了」は、OKと対象外の合計です。確認中・要検討の項目は完了に含みません。
    • 記録はお使いのブラウザ（localStorage）にのみ保存されます。ブラウザのデータを消去すると記録も消えるため、定期的に「データを書き出す」でバックアップしてください。
