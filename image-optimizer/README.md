# 画像一括最適化ツール（Web制作向け）

ホームページ制作の画像準備を一括で自動化するブラウザアプリです。
`index.html` をブラウザで開くだけで動作します（サーバー・インストール不要）。
**処理はすべてローカル（ブラウザ内）で完結し、画像が外部に送信されることはありません。**

## 機能

| # | 機能 | 内容 |
|---|------|------|
| ① | ドラッグ＆ドロップ | 複数枚まとめて対応。ファイル選択・クリップボード貼り付け（Ctrl+V）も可 |
| ② | 自動判定 | 透過・色数・サイズ・縦横比を解析し、写真→WebP／ロゴ・アイコン→PNG／イラスト→WebP を自動判別（手動変更可） |
| ③ | 一括リネーム | プレフィックス＋連番（`company-office-01.webp` など）。分類ごと連番／全体連番を選択可 |
| ④ | サイズ変更 | 1920 / 1600 / 1200 / 800 / カスタム。横幅・長辺基準を選択可。**元画像より拡大しない** |
| ⑤ | 圧縮率 | 品質 100 / 90 / 85 / 80 / 75（制作向けは85推奨） |
| ⑥ | WordPress向け設定 | WebP変換・元画像保持・小文字化・半角英数字のみ・スペース削除・日本語削除・alt候補生成・width/height取得 |
| ⑦ | ZIPダウンロード | 変換後の画像＋（オプションで）元画像＋CSVをまとめて `images.zip` に |
| ⑧ | CSV出力 | `ファイル名,alt,width,height,変換前(KB),変換後(KB)`（BOM付きUTF-8・Excel対応） |

## さらに便利な機能

- EXIFの向きを自動補正
- 透過PNGを維持したまま圧縮（JPEG出力時のみ白背景で合成）
- WebP・PNG・JPEG・AVIFの一括変換（AVIFはブラウザのエンコード対応時のみ）
- 変換前後のファイルサイズ比較表示（個別＋合計削減率）
- 同名ファイルの重複自動回避（`-2`, `-3` を付与）
- アイコン分類からファビコン一式生成（16 / 32 / 180px PNG）
- OGP画像（1200×630 中央クロップ）を行ごとのチェックで追加生成
- SWELL向け命名プリセット候補（`fv-hero` / `about-office` / `interview` など、プレフィックス入力で候補表示）

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 画像をドロップ → 自動で分類・形式・ファイル名・altが提案される
3. 必要に応じて一覧で個別調整（分類・形式・名前・alt・OGP）
4. 「変換する」→「ZIPでダウンロード」

## 自動判定のロジック

AIモデルは使わず、軽量な画像解析ヒューリスティクスで判定しています。

- 透過あり＋小さい正方形 → **アイコン**（PNG）
- 透過あり＋色数少なめ → **ロゴ**（PNG）
- 透過あり＋色数多い → **イラスト**（WebP）
- 不透過＋色数少ない → **イラスト／バナー**（WebP）
- 横長（縦横比 2.6 超）→ **バナー**（WebP）
- それ以外 → **写真**（WebP）

判定はあくまで候補なので、一覧のプルダウンでいつでも変更できます。

## 制限事項

- 動画・SVGは対象外（ラスター画像のみ）。アニメGIFは先頭フレームのみ変換されます
- AVIFエンコードは現行の主要ブラウザでは未対応のため、通常は選択不可と表示されます
- altの「内容」推定はヒューリスティクス（分類名＋元ファイル名）です。写真の被写体認識まで行う場合はAI APIの組み込みが必要です
