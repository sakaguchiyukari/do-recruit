# 安否確認システム（700名規模）

災害・緊急時に、社員の安否を **スマホから30秒で回答** → **管理画面でリアルタイム集計** するシステムです。
フロントは静的な HTML/CSS/JS、バックエンドは Google Apps Script（GAS）＋ Google スプレッドシートで動きます。サーバー代は不要です。

## ファイル構成

```
safety-check/
├── index.html              … 社員の回答画面
├── admin.html              … 管理画面（集計・部署別・一覧・CSV出力）
├── css/style.css           … スタイル（1ファイル / BEM / CSS変数）
├── js/
│   ├── config.js           … 設定（GAS の URL など）
│   ├── common.js           … 共通処理（API通信・フェードイン・デモデータ）
│   ├── answer.js           … 回答画面の処理
│   └── admin.js            … 管理画面の処理
├── img/favicon-safety.svg
└── gas/
    ├── Code.gs             … GAS バックエンド
    └── employees_template.csv … 社員マスタの入力例
```

## まず動かしてみる（デモモード）

`js/config.js` の `GAS_ENDPOINT` が空のときは **デモモード** で動きます（700名のダミーデータをブラウザ内に保存）。

- 回答画面：`index.html`　社員番号 `100001`〜`100700`、確認コード `1234`
- 管理画面：`admin.html`　管理キーは任意の8文字以上（例 `demo1234`）

ブラウザで直接開いても動きますが、ローカルサーバー経由がおすすめです。

```bash
cd safety-check && python3 -m http.server 8080
```

## 本番セットアップ

1. **スプレッドシートを作成** → 「拡張機能 > Apps Script」を開き、`gas/Code.gs` の内容を貼り付けて保存
2. 関数 `setup` を選んで実行（初回は権限承認あり）
   → シート「社員マスタ / 回答 / イベント」が作成され、**実行ログに管理キー** が出力されます
3. 「社員マスタ」に 700名分を貼り付け（`gas/employees_template.csv` の列順）
   - 確認コードが空の社員には `generatePins` 実行で4桁を自動発番できます
4. 「デプロイ > 新しいデプロイ > 種類：ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（社員が Google ログインなしで回答できるようにするため）
5. 発行された `https://script.google.com/macros/s/.../exec` を `js/config.js` の `GAS_ENDPOINT` に設定
6. HTML 一式を社内サーバー / レンタルサーバー / GitHub Pages などに配置
7. 管理画面でログイン → **「新しい安否確認を開始」** で受付開始

### 通知メール（任意）

- Apps Script の「プロジェクトの設定 > スクリプトプロパティ」に `ANSWER_URL`（回答画面URL）を追加
- `sendNotification`：全社員へ回答依頼メールを送信
- `sendReminder`：未回答者だけに再送（時間主導トリガーで30分おきなども可）

> ⚠ MailApp には1日の送信数上限があります。Google の公式ドキュメント（Apps Script の「Quotas」）では、無料の Gmail アカウントは 1日 100 通、Google Workspace は 1日 1,500 通とされています（2026年時点の記載。変わる可能性があるため最新版を確認してください）。
> 700名に送るなら **Google Workspace アカウントでの運用が前提** です。上限を超える場合は送信前に処理を止めるようにしてあります。
> 災害時はメールが遅れることもあるため、社内チャット・LINE WORKS などで回答URLを同時に周知することをおすすめします。

## セキュリティ・運用メモ

| 項目 | 対応 |
|---|---|
| なりすまし | 社員番号＋4桁の確認コードで本人確認 |
| 総当たり | 同じ社員番号で5回失敗すると10分ロック |
| 管理画面 | 管理キー（推測できない32文字）がないと集計を取得できない。確認コード・メールは画面に返さない |
| 同時送信 | `LockService` で書き込みを順番に処理。フロント側でも通信失敗時に自動再送 |
| 数式インジェクション | `=` などで始まる入力値はシート保存時・CSV出力時に無害化 |
| 再回答 | 同じイベント内では最新の回答で上書き |

- 管理画面の URL は社内にだけ共有し、管理キーは担当者以外に渡さないでください。
- 年1回程度、**訓練として実際に「安否確認を開始」して回答してもらう** と、確認コード忘れなどの問題を本番前に見つけられます。
