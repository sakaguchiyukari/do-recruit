# ポートフォリオサイト —「夜の森」エディション

`index.html` 1ファイルだけで完結するポートフォリオサイトです。
HTML・CSS・JavaScript・演出のすべてが1ファイルに入っているので、
エックスサーバーにこのファイルをアップロードするだけで公開できます。
**外部ライブラリ・CDNは一切使っていません**（＝表示が速く、依存もありません）。

## 実装している演出（すべて自前のVanilla JS / CSS）

| 演出 | 説明 |
|---|---|
| 幕開けローディング | 「想いを、かたちに。」が一文字ずつ灯り、幕が上がる |
| 夜の森Canvas | ヒーロー背景に霧の光と蛍。マウスに合わせて視差が動く |
| 文字の立ち上がり | 見出しが1文字ずつ回転しながら現れる（IntersectionObserver） |
| カスタムカーソル | 金の輪がリンクで膨らみ、実績上では「VIEW」表示 |
| カーソル追従プレビュー | 制作実績にホバーするとブラウザ風の窓が付いてくる |
| スキルの帯 | 無限ループのマーキー |
| カウントアップ | 実績数字がスクロールで加算される |
| 灯りをたどるFLOW | スクロールに合わせて金の線が伸び、各ステップの灯がともる |
| 磁力ボタン | CONTACTボタンがカーソルに吸い付く |
| 紙の質感 | 全面にフィルムグレイン |
| スクロール進捗バー | 画面上部に苔色→金のグラデーション |

- **BEM設計**・**レスポンシブ対応**（900pxでナビ切替、ドロワーメニュー）
- **prefers-reduced-motion 対応**（動きを減らす設定の人には演出を止めて表示）
- タッチ端末ではカスタムカーソル等を自動で無効化

## エックスサーバーへのアップロード方法

1. サーバーパネルでサブドメインなど公開先を用意
2. ファイルマネージャー（またはFTP）で `index.html` をアップロード
3. 必要に応じてBasic認証を設定
