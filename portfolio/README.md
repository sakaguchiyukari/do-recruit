# ポートフォリオサイト

`index.html` 1ファイルだけで完結するポートフォリオサイトです。
HTML・CSS・JavaScript がすべて1ファイルにまとまっているので、
エックスサーバーにこのファイルをアップロードするだけで公開できます。

## 特徴

- **BEM設計** … `.works__card` `.works__title` のような命名規則で整理
- **IntersectionObserver** … スクロールに合わせたふわっと表示（`.js-fade`）
- **レスポンシブ対応** … スマホ〜PCまで対応（900pxでナビ切り替え）
- **アクセシビリティ配慮** … `prefers-reduced-motion` 対応、aria属性つきハンバーガーメニュー
- **外部ライブラリなし** … CDN不要ですべて自前実装（表示が速い・依存なし）

## 公開前に確認・修正してほしい箇所

すべて `index.html` 内を検索すれば見つかります。

### 1. お名前
`Yukari Sakaguchi` / `Y.SAKAGUCHI` を検索して、表記を確認してください
（漢字表記にしたい場合はここを変更）。

### 2. 制作実績の説明文
各サイトの説明文（`works__desc`）は **ドメイン名からの推定で仮置き** しています。
実際のサイト内容に合わせて修正してください。特に：

- `かたるの森` … サイト名・業種を確認
- `採用サイト` `宿泊施設サイト` `キャンプ場サイト` `コーポレートサイト` … 正式なサイト名に変更可

### 3. 実績のスクリーンショット
現在はグラデーション＋ドメイン名の仮サムネイルです。
実際のスクリーンショットに差し替える場合は、`images/` フォルダを作って
各カードの `works__thumb` 内に img タグを追加してください：

```html
<div class="works__thumb works__thumb--01">
  <img src="images/katarunomori.jpg" alt="かたるの森 サイトのスクリーンショット">
</div>
```

img を入れると仮サムネイルの上に自動で表示されます（CSSは対応済み）。
スクリーンショットは幅1200px程度・WebP形式がおすすめです。

### 4. お問い合わせ先
CONTACTセクションのメールアドレス（`mailto:`）を確認してください。
Googleフォームを使う場合は `href` をフォームのURLに差し替えるだけでOKです。

### 5. 掲載許可
実績はすべて勤務先のサイトのため、**掲載前に会社の許可を取ることをおすすめします**。
許可が難しいサイトは、カードごと削除するか「非公開実績」としてURL・サイト名を伏せてください。

## エックスサーバーへのアップロード方法

1. サーバーパネル → サブドメイン設定などで公開先を用意
2. ファイルマネージャー（またはFTP）で `index.html` をアップロード
3. 一般公開前に見せたくない場合は、サーバーパネルの「アクセス制限」で Basic認証を設定
