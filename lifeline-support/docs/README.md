# ライフラインサポート

> 地震後の暮らしを支える防災ツール（PWA / オフライン対応）

被災後に「避難所に行かず自宅で暮らす（在宅避難）」人のための道具です。
情報を並べるだけの防災サイトではなく、**今の状況に必要なものだけを、優先度順に出す**ことを目的にしています。

- 作成日：2026-07-29
- ディレクトリ：`lifeline-support/`
- ブランチ：`claude/disaster-lifeline-support-8ekv71`

---

## 1. 何ができるか

| 機能 | 内容 |
|---|---|
| **状況で絞り込む** | 停電・断水・トイレ・通信障害・ガス停止・食料不足から、いま起きていることを選ぶ。選んだ状況の対策だけが優先度順に並ぶ |
| **世帯条件で絞り込む** | 乳幼児・高齢者・ペット・持病／医療機器・妊娠中。該当者向けの注意が結果に差し込まれる |
| **組み合わせに答える** | 「停電＋断水」のように条件が重なると、その組み合わせ専用の対策（`combo`）が最上位に出る |
| **現在の状況バー** | 選択中の状況が全ページの上部に常時表示され、どのページでも前提を見失わない |
| **チェックの記録** | 「今すぐやること」をチェックでき、進捗バーで残りが分かる。端末に保存される |
| **地域設定** | 都道府県から一般送配電事業者を自動判定。市区町村名を入れると自治体・水道局・ガス会社の検索リンクが生成される |
| **公的機関リンク集** | 13カテゴリ・77件。全カードに「検索して探す」を併設し、URLが変わっても行き止まりにならない |
| **緊急メモ** | 家族の連絡先・落ち合う場所・持病と薬を端末内にだけ保存。通信がなくても開ける |
| **省電力表示** | 黒基調の表示に切り替え。暗闇で目が慣れること、有機ELの消費電力を抑えることが目的 |
| **オフライン対応** | Service Worker で全ページ・全データを端末に保存。圏外でも全機能が動く |

## 2. ディレクトリ構成

```
lifeline-support/
├── index.html                  # ホーム（状況の選択と結果）
├── lifehacks/index.html        # ライフハック集（カテゴリ別の全件）
├── links/index.html            # 公的機関リンク集
├── memo/index.html             # 緊急メモ
├── about/index.html            # 使い方・情報の扱い・免責事項
├── manifest.webmanifest        # PWA マニフェスト
├── sw.js                       # Service Worker（オフライン対応の中核）
│
├── assets/
│   ├── css/style.css           # 全スタイル（1ファイル＝1リクエスト）
│   ├── icon/                   # icon.svg / icon-192 / icon-512 / maskable / apple-touch
│   └── js/
│       ├── app.js              # ホーム
│       ├── page-lifehacks.js   # ライフハック集
│       ├── page-links.js       # リンク集
│       ├── page-memo.js        # 緊急メモ
│       ├── page-static.js      # 文章だけのページ（about）
│       ├── modules/
│       │   ├── state.js        # localStorage による状態管理
│       │   ├── render.js       # カードの描画
│       │   ├── dom.js          # 要素生成ヘルパー
│       │   ├── theme.js        # 表示モード（ダーク／省電力）
│       │   ├── pwa.js          # Service Worker 登録・オンライン検知・インストール
│       │   └── status-bar.js   # 「現在の状況」バー
│       └── data/
│           ├── situations.js   # 状況・世帯条件・都道府県→電力会社
│           ├── items.js        # 対策コンテンツ本体（133件）
│           └── links.js        # 公的機関リンク（77件）
└── docs/README.md              # 本書
```

### 設計上の判断

- **ビルド工程なし。** npm も バンドラも使わない。素の ES モジュールと CSS だけで動く。
  災害用のツールが「ビルドが通らないから更新できない」状態になるのを避けるため。
- **CSS は1ファイル。** `@import` の直列読み込みを避け、1リクエストで全部そろうようにした。
- **外部リソースはゼロ。** Web フォントも CDN も解析タグも読み込まない。オフラインで確実に動くことと、
  被災者の通信量を1バイトも無駄にしないことを優先した。
- **コンテンツの情報源は1か所。** ホームの絞り込みもライフハック集も `data/items.js` だけを読む。
  同じ文章を2か所に書かない。

## 3. コンテンツの追加・修正のしかた

### 対策を1件足す

`assets/js/data/items.js` の `ITEMS` に追記するだけで、ホームにもライフハック集にも反映されます。

```js
{
  id: 'bo-now-09',            // 一意。公開後は変更しない（チェック状態の保存キー）
  kind: 'now',                // 'now' | 'hack' | 'caution'
  situations: ['blackout'],   // 対象の状況（1つでも選ばれていれば表示）
  households: [],             // 対象の世帯条件（空なら全員向け）
  priority: 2,                // 1〜5。小さいほど上に出る。1は命に直結
  title: '一目で行動が分かる短い文',
  body: '目安の数値を単位付きで書く。「〜しましょう」ではなく言い切る。',
}
```

複数の状況が重なったときだけ出したい項目は `combo` を付けます。

```js
{
  id: 'cb-bo-wa-03',
  situations: ['blackout', 'water'],
  combo: ['blackout', 'water'],  // 両方選ばれたときだけ表示され、最上位に出る
  ...
}
```

### 表示順のルール

1. `combo`（組み合わせ専用）が最優先
2. `priority` の小さい順
3. 同じ `priority` なら、世帯条件つきの項目が先（少数の人にしか当てはまらない情報は埋もれやすいため）

### リンクを1件足す

`assets/js/data/links.js` の `LINKS` に追記します。`search` は必須にしてください（リンク切れ時の逃げ道）。

### 内容を更新したら

`sw.js` の `CACHE_VERSION` を必ず上げてください。上げないと、すでに保存している利用者に更新が届きません。

```js
const CACHE_VERSION = 'lifeline-support-v2';  // v1 → v2
```

利用者の画面には「新しい内容が届いています／更新する」が出ます。
閲覧中に内容が入れ替わると混乱するため、自動では切り替えません。

## 4. 公開するときの注意

### HTTPS が必須

Service Worker は HTTPS（または localhost）でしか動きません。
HTTP で公開すると、オフライン対応というこのアプリの中核が丸ごと機能しません。

### サブディレクトリ公開に対応済み

すべてのパスを相対で書いているため、`https://example.com/lifeline-support/` のような
サブディレクトリ配下でもそのまま動きます。下層ページから `sw.js` を見つけるために
`<html data-app-root="../">` を使っています。新しいページを足すときはこの属性を忘れずに。

### 動作確認

```bash
cd lifeline-support
python3 -m http.server 8000
# → http://localhost:8000/
```

`localhost` なら Service Worker も登録されるので、DevTools の Network を Offline にして
全ページが開けることを確認してください。

## 5. 公開前に確認をお願いしたいこと

このアプリは実装として完成していますが、**公開前に以下の確認をおすすめします**。

### ① 掲載URLの再確認（重要）

リンク先は公開情報をもとに、**改称・移転が起きにくいトップページ**を選んでいます。
それでも組織再編（例：水道行政の所管省庁の変更、送配電会社の分社）でURLは変わります。
公開前に一度、全77件の疎通確認をしてください。
なお全カードに「検索して探す」を付けてあるため、リンクが切れても利用者は行き止まりになりません。

### ② 防災・医療の専門家によるレビュー

内容は公的機関が公開している防災の考え方と、過去の災害で共有されてきた対処法を、
在宅避難の場面で使いやすい形に整理したものです。
とくに以下は、専門家の確認を経てから公開する価値があります。

- 医療機器・常用薬に関する記述（`households: ['medical']` の項目）
- 妊娠中の人に関する記述（`households: ['pregnant']` の項目）
- ガスのマイコンメーター復帰、通電火災、一酸化炭素中毒に関する記述

### ③ 数値の位置づけ

「水は1人1日3L」「トイレは1人1日5回」などは**目安**です。
季節・体格・健康状態で変わることを、`about/` ページに明記しています。

### ④ 自治体との連携（任意）

地域設定は現在「検索リンクの生成」で実現しています。
特定の自治体と連携する場合は、`data/links.js` にその自治体の
給水情報・避難所一覧の直リンクを追加すると、さらに実用的になります。

## 6. アクセシビリティ・パフォーマンス

- タップ領域は最小 44×44px
- 選択状態を色だけで伝えない（`✓ ON` の文字を併記）
- 状況の選択・チェックはネイティブの `<input type="checkbox">` が土台。キーボードと読み上げでそのまま動く
- 結果の件数は `role="status" aria-live="polite"` で読み上げに通知
- `prefers-reduced-motion: reduce` でアニメーションを停止
- `prefers-color-scheme` に追従。手動のダーク／省電力表示も選べる
- 印刷用スタイルあり（紙に出して冷蔵庫に貼れる。電池が尽きたときの最後の手段）
- 外部リソース・追跡タグ・Cookie なし。入力内容は端末外に出ない
