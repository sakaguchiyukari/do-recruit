# クライアント共有ポータル (Client Portal Lite)

ヒアリングと進捗報告を、クライアントに専用URLで**ログイン不要**で共有できるWordPressプラグインです。
SWELLなど今お使いのテーマとそのまま併用できます（テーマの見た目に依存しない独立ページとして表示されます）。

## できること

- 案件（クライアント）ごとにヒアリング項目を設定し、クライアントが直接回答を入力
- 進捗ログを日付・ステータス・メモで記録し、クライアント専用ページにタイムライン表示
- クライアントからのメッセージ・質問を受け取り、管理画面から返信
- クライアントが回答/メッセージを送るとメール通知（進捗更新時にクライアントへ通知することも可能）

## インストール（FTP）

1. `client-portal-lite` フォルダごと、エックスサーバーのFTPで
   `/public_html/(サイトのディレクトリ)/wp-content/plugins/` にアップロード
2. WordPress管理画面 → 「プラグイン」→ 「クライアント共有ポータル」を**有効化**

## 使い方

1. 管理画面の左メニューに追加される「クライアント案件」から**新規案件を追加**
2. タイトルに案件名（例: 「〇〇様 コーポレートサイト制作」）を入力
3. 右側の「案件設定・共有URL」で
   - ステータスを選択
   - クライアントのメールアドレス（任意。入力すると通知が送れます）
   - ヒアリング項目を1行1項目で入力（例: 「サイトの目的」「希望の色味」「参考にしたいサイト」）
4. 「公開」ボタンで保存すると、**クライアント共有URL**が発行されます
5. 「URLをコピー」ボタンでコピーし、メールやチャットワーク・LINEなどでクライアントに送るだけ
6. クライアントはそのURLにアクセスすると：
   - ヒアリング項目に回答して送信できる
   - 進捗タイムラインを見られる
   - メッセージを送れる
7. 作業が進んだら「進捗ログ」の欄からステータスとメモを追加。「クライアントに通知メールを送る」にチェックすると、クライアントへ自動でメールが届きます
8. クライアントからの回答は「ヒアリング回答」、メッセージは「クライアントとのメッセージ」の欄で確認・返信できます

## セキュリティについて

- 共有URLにはランダムな長いトークンが含まれており、URLを知っている人だけがアクセスできる仕組みです（Googleドキュメントの共有リンクと同じ考え方）
- 検索エンジンにインデックスされないよう `noindex` を指定しています
- URLは案件終了後も生き続けるため、案件が完了したら投稿を非公開/削除するか、クライアントに「このURLは以後使用しません」と伝えることをおすすめします
- より高いセキュリティが必要な場合（金額や個人情報を多く扱う案件など）は、簡易パスワード保護の追加も可能です。必要であればご相談ください

## 注意点

- メール通知には `wp_mail()`（WordPress標準のメール送信機能）を使用しています。エックスサーバーでは標準で送信できますが、迷惑メール判定が気になる場合はWP Mail SMTPなどのプラグイン併用をおすすめします
- 案件数が多くなってきたら、通常の投稿と同じように「クライアント案件」の一覧から検索・絞り込みができます
