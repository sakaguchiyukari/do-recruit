# ホームページ集客診断AI

URLを入れるだけでAIがサイトを診断し、改善リスト・キーワード・記事案・記事原稿を生成する一枚ページです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 診断ページ本体（フォーム・結果表示・記事生成UI） |
| `claude-proxy.php` | Claude APIへの中継役。APIキーをサーバー側だけで保持する |

## なぜプロキシ（PHP）が必要か

元のHTMLはブラウザから直接 `api.anthropic.com` を呼ぶ作りでした。これは **Claude.ai のアーティファクト環境内でだけ動く特別な仕組み** で、通常のWebサーバーにアップすると次の理由で必ず失敗します（「診断に失敗しました」の原因）。

1. APIキーが付いていない（認証エラー）
2. 必須ヘッダー `anthropic-version` がない
3. ブラウザからの直接呼び出しはCORSで制限される

かといってAPIキーをHTMLに書くと、ページを見た人全員がキーを盗めてしまいます。そのため `claude-proxy.php` がサーバー側でキーを持ち、ブラウザ→PHP→Claude API の順に中継します。

## 設置手順

1. `index.html` と `claude-proxy.php` を **同じディレクトリ** にアップロードする（PHPが動くサーバーであること）
2. [Anthropic Console](https://console.anthropic.com/) でAPIキー（`sk-ant-` で始まる文字列）を発行する
3. APIキーを設定する。どちらか一方でOK:
   - サーバーの環境変数 `ANTHROPIC_API_KEY` に設定する（推奨）
   - `claude-proxy.php` の冒頭 `$apiKey = getenv('ANTHROPIC_API_KEY') ?: '';` の `''` に直接記入する
4. ブラウザで `index.html` を開き、URLを入力して診断できれば完了

## 注意事項

- **APIキーを直接記入した場合、このファイルをGitの公開リポジトリにコミットしないでください。**
- 診断1回ごとにAPI利用料が発生します（Web検索を含むため1回あたり数円〜十数円程度）。誰でもアクセスできる場所に公開する場合は、Basic認証やレート制限の追加を検討してください。
- 診断には30秒〜1分ほどかかります。サーバーのPHP実行時間制限（`max_execution_time`）が極端に短い場合は延長してください（プロキシ内で180秒に設定を試みています）。
