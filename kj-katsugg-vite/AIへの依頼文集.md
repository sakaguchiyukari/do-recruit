# AIへの依頼文集

コピーして、AIエージェントにそのまま貼って使う依頼文のテンプレ集です。〈 〉の部分は自分の内容に書き換えてください。

## 開発環境の立ち上げ

```
はじめにお読みください.md を読んで、この開発環境の立ち上げを手伝ってください。
表示の確認は私がブラウザで行います。
```

## セクションの追加

```
トップページに「〈お知らせ〉」セクションを追加してください。
内容は〈日付とタイトルを3件並べるシンプルなもの〉でOKです。
```

## 下層ページの追加

```
下層ページ「〈about〉」を追加してください（〈about/index.html〉）。
必要な設定の追記もあわせてお願いします。
```

## 修正の依頼

```
〈FV〉セクションの〈キャッチコピー〉を「〈新しい文言〉」に変更してください。
```

## 作業の再開（セッションをまたいだとき）

```
PLAN.md を読んで、続きからお願いします。
```

## 実装のレビュー（書いた本人ではない、新しいセッションで）

```
rules/ を読んで、今回の変更をレビューしてください。
```

---

依頼文は、案件で使うたびに自分の型に育てていってください。よく使う形ができたら、このファイルに追記しておくと、次の案件でもそのまま使えます。
