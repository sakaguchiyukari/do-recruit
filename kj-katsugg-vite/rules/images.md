# 画像とWebPの扱い

このテンプレートは画像まわりが自動化されています。仕組みを壊さない置き方をします。

## 置き場所

画像は必ず `images/` に置きます。フォルダ分けしてもかまいません（`images/fv/` など）。

- `images/` に置いた jpg / png から、**同じ名前の `.webp` が自動で作られます**
- `npm run build` のときに、jpg は圧縮されます
- ビルド後は `dist/images/` に、フォルダ構成そのままで出力されます

`images/` 以外の場所に置くと、この自動化が効きません。

## HTMLでの書き方

WebPを優先し、対応していないブラウザ向けに元画像を残します。

```html
<picture>
  <source srcset="./images/photo.webp" type="image/webp">
  <img src="./images/photo.jpg" alt="説明" width="1200" height="800" loading="lazy">
</picture>
```

- `.webp` は自動生成されるので、**自分で用意する必要はありません**
- `alt` `width` `height` は `<img>` 側に書きます

## 自動生成された .webp は編集しない

`images/` の中の `.webp` は元画像から作られたものです。直接編集しても、次のビルドで作り直されます。差し替えるときは**元のjpg / pngを差し替えます**。

## 画像の形式の選び方

| 用途 | 形式 |
|---|---|
| 写真 | jpg（webpが自動で作られる） |
| ロゴ・アイコン・イラスト | svg |
| 透過が必要な画像・グラデーション | png（webpが自動で作られる） |

png を jpg に変換して透過を失わないよう注意します。

## やらないこと

- 画像を手作業で圧縮してから置き直す（二重に圧縮されて画質が落ちます）
- `dist/` の中の画像を直接差し替える（ビルドで消えます）
