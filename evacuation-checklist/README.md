# 避難所 持ち物チェックリスト

被災した方が、自分の状況に合わせた持ち物をその場で確認できるツールです。

状況（世帯・赤ちゃん・高齢者・ペットなど）を選ぶと、必要な持ち物と数量の目安が
自動で切り替わります。チェック状態と記入内容は端末に自動保存され、
印刷・PDF保存で紙に残せます。

```
evacuation-checklist/
├── index.html                  ページ本体
├── manifest.webmanifest        ホーム画面に追加するための定義
├── sw.js                       オフライン用 Service Worker
└── assets/
    ├── css/style.css           全スタイル（印刷用レイアウトを含む）
    ├── js/app.js               表示・保存・印刷のロジック
    ├── js/data/items.js        持ち物データ（★ 中身の更新はここだけ）
    └── img/icon*.svg           アプリアイコン
```

## 開き方

ビルドもインストールも不要です。目的に応じて3通りあります。

### A. とりあえず中身を見る（いちばん簡単）

`dist/避難所持ち物チェックリスト.html` をダウンロードして、ダブルクリックするだけです。
HTML 1枚に全部入っているので、これだけで全機能が動きます。

`dist/` はリポジトリに含まれないため、手元に無い場合は
`node build-single-file.js` を実行すると生成されます。

### B. リポジトリを手元に取ってくる

```bash
git fetch origin claude/evacuation-checklist-tool-06ex49
git checkout claude/evacuation-checklist-tool-06ex49
open evacuation-checklist/index.html      # Windows は start、Linux は xdg-open
```

GitHub の画面からなら、ブランチを選んで
「Code → Download ZIP」で落とし、解凍後に
`evacuation-checklist/index.html` をダブルクリックしても同じです。

### C. サーバに置いて公開する

このフォルダごとアップロードしてください。
**HTTPS で配信したときだけ** Service Worker が有効になり、
一度開いたあとは通信が無くても開けるようになります。
スマートフォンでは「ホーム画面に追加」でアプリのように使えます。

避難所で配る想定なら、この形が本来の姿です。

## 設計方針

被災地で使われる前提から、通常の Web 制作とは違う判断をしている箇所があります。

### 1. 通信が無くても必ず動く

外部 CDN・Web フォント・解析タグを一切読み込みません。
圏外や輻輳のときに、外部リソース待ちで真っ白な画面になることを避けるためです。
アイコンも絵文字と自前の SVG だけで賄っています。

### 2. `file://` で直接開いても動く

コーポレートサイト（`doyg-corporate-site`）は ES module 方式ですが、
**このツールだけは意図的に classic script にしています。**
ES module は `file://` では CORS で読み込めず、
フォルダをダウンロードして開いた人の画面が真っ白になるためです。

停電・圏外の状況で「開いたのに動かない」は許容できないため、
コード規約の統一よりも確実に動くことを優先しました。

### 3. 保存ボタンを置かない

入力のたびに自動保存します（localStorage、約0.4秒のデバウンス）。
この状況にある人に「保存し忘れて消えた」を起こしてはいけないためです。
プライベートブラウジング等で localStorage が使えない場合も、
アプリは動き続け、その旨を画面に表示します。

### 4. PDF は `window.print()` で出す

PDF 生成ライブラリを積むと、ライブラリ本体に加えて
日本語フォントの埋め込みで数 MB の追加ダウンロードが必要になります。
回線が細い状況では現実的ではありません。

ブラウザの印刷ダイアログから「PDF に保存」を選べば、
追加ダウンロードゼロで日本語も確実に出力できます。
「印刷する」「PDFで保存」の2ボタンは同じ処理を呼びますが、
利用者が探す言葉が違うため、あえて分けています。

### 5. 紙になったときが本番

印刷用スタイルは「電池の要らない防災グッズ」を作るつもりで組んでいます。

- 操作 UI（選択チップ・ボタン・進捗バー）は印刷しない
- チェックボックスは、その場で手書きできる枠付きの四角として描き直す
- メモ欄は入力欄を隠し、**同じ内容を複製した通常テキストを印刷する**
  （textarea のまま印刷すると、入りきらない行が丸ごと欠落するため。
  緊急連絡先が紙から消えるのは致命的です）
- 未記入のメモ欄は、手書きできる罫線として出力する

### 6. 不安をあおらない

赤は「持ち物より命が最優先」の一文と、0次持ち出しの見出しにだけ使い、
基調は落ち着いた藍色にしています。
進捗の文言も、未チェックを責める表現を避けています。
避難所の夜に使えるよう、ダークモードにも対応しています。

## 持ち物データの更新

`assets/js/data/items.js` だけを編集してください。表示ロジックには触れずに済みます。

```js
{
  id: 'bag-water',              // 保存キー。公開後は変更しない（チェックが外れます）
  label: '飲料水（持ち出し用）',
  note: '重いので無理は禁物。…',  // なぜ必要か・選び方の一言
  cat: 'life',                  // CATEGORIES のキー
  pri: 'bag',                   // now（0次）／ bag（1次）／ later（2次）
  when: ['base'],               // 表示条件。いずれか1つ該当すれば表示
  qty: qtyWaterBag,             // 人数から数量を計算する関数（省略可）
}
```

`when` に使えるキー:

| キー | 意味 |
| --- | --- |
| `base` | 常に表示 |
| `solo` / `couple` / `family` | 世帯タイプ |
| `baby` / `senior` / `pet` / `woman` | 該当者がいる場合 |
| `medicine` / `allergy` / `care` | 持病・アレルギー・要配慮 |

数量の根拠（一般的な備蓄指針に準拠）:

- 飲料水 … 1人1日 3L
- 非常食 … 最低3日分、可能なら7日分
- 簡易トイレ … 1人1日 5回

内容を更新したら、`sw.js` の `CACHE_NAME` を上げてください。
古いキャッシュが破棄され、利用者の端末に新しい内容が届きます。

## 動作確認済みの項目

Chromium で以下を確認しています。

- 条件の切り替えによる項目の増減（58 → 73件）
- 人数・日数に追随する数量計算（4人3日 = 36L → 5人4日 = 60L）
- 入力値の上下限クランプと ± ボタンの無効化
- リロード後のチェック・メモの復元
- オフライン（機内モード相当）での再訪問
- `file://` で直接開いた場合の全機能
- 印刷レイアウト（長い連絡先リストが欠落しないこと）
- ダークモード

## 注意

持ち物の数量は一般的な目安です。利用者の体力・健康状態に合わせた調整が前提です。
避難の判断そのものは、必ず自治体の情報と現地の状況が優先されます。
その旨はページ下部にも明記しています。

## 1ファイル版

`node build-single-file.js` を実行すると、CSS と JS を埋め込んだ
HTML 1枚だけの版が `dist/` に出力されます。

```
dist/避難所持ち物チェックリスト.html   ← ダブルクリックで開ける（約87KB）
dist/artifact.html                      ← 外側の骨組みを持たない断片版
```

フォルダごとの配布ができない場面（メール添付、USBメモリ、LINEでの送信など）で
使ってください。1ファイル版は Service Worker を持ちませんが、
ファイル自体が手元にあるため、オフラインでも開けます。

`dist/` はビルド生成物なのでコミット対象外です。
